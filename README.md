# MaryenB 가상 쇼핑몰

GitHub Pages 업로드·배포는 [GITHUB-PAGES.md](GITHUB-PAGES.md)를 참고하세요. `main` push 시 자동 배포하며 Pages 버전은 브라우저 저장소 기반의 시연용입니다.

Next.js 기반의 세럼 쇼핑 체험 사이트입니다. 기본값은 가상 DB 모드이며 실제 PostgreSQL이나 결제 가맹점 키가 필요하지 않습니다.

## 실행

PowerShell에서 프로젝트 경로를 먼저 선택합니다.

```powershell
Set-Location -LiteralPath C:\git\maryenb
npm.cmd install
npm.cmd run dev -- --port 3100
```

접속 주소는 http://localhost:3100 입니다. 같은 포트에 기존 서버가 있으면 그 서버를 종료한 뒤 실행합니다. 개발 서버는 수정 내용을 자동 반영합니다.

프로덕션 실행은 `npm.cmd start -- --port 3100`을 사용합니다. prestart가 최신 소스를 자동으로 빌드합니다. 이미 실행 중인 프로덕션 서버는 소스 파일을 수정해도 자동 갱신되지 않으므로 종료 후 다시 시작해야 합니다.

이 PC에서는 127.0.0.1:3000에 별도의 서버가 실행되고 있어 localhost:3000과 다른 페이지가 나타날 수 있습니다. MaryenB 확인에는 3100 포트를 사용합니다.

## 가상 구매

장바구니와 주문서는 로그인 후 사용할 수 있습니다. `/login`에서 시연용 계정을 가입하거나 게스트로 입장하세요. 가입 계정과 세션은 `.data/auth.json`에 저장되며 비밀번호는 salt를 적용한 scrypt 해시로 보관합니다. 세션 쿠키는 HttpOnly이고 로그아웃 시 서버 세션도 삭제됩니다. 회원 세션은 7일, 게스트 세션은 1일간 유지됩니다. 장바구니는 브라우저에서 계정별로 분리합니다. 시연 계정에는 실제 비밀번호를 사용하지 마세요.

- 6종 모두 재고 100개에서 시작하며 실제 주문 수량만큼 감소합니다.
- ANC5 15,700원, ANC10 16,900원이며 나머지 상품은 기존 가격을 유지합니다.
- 상품 상세 → 바로 구매하기 → 배송정보 및 결제수단 선택 → 가상 주문 완료.
- 네이버페이·카카오페이·토스페이·KG이니시스는 가상 체험이며 실제 청구나 배송은 없습니다.
- 배송정보에는 예시 값을 입력하세요. 가상 주문에는 배송 개인정보를 저장하지 않습니다.
- `.data/virtual-db.json`에 주문과 재고를 저장하며 서버 재시작 후에도 유지합니다. 파일이 없으면 초기 카탈로그로 시작합니다.

`DB_MODE=virtual`이 기본값이며 `.env`가 없어도 동작합니다. 실운영 설정은 `DB_MODE=real`로 명시해야 합니다. 자세한 내용은 [PAYMENTS.md](PAYMENTS.md)를 참고하세요.

## 실제 서버 상태 확인

브라우저에서 http://localhost:3100/api/checkout 을 열었을 때 `virtual: true`, 네 결제수단의 `enabled: true`가 표시되어야 최신 가상 쇼핑 버전입니다.
http://localhost:3100/api/products 에서 6종의 가격과 남은 재고를 확인할 수 있습니다.

2026년 11월 17일 실제 실행 서버에서 6종 상세페이지, 네 가지 가상 결제수단, 가상 주문 6건과 재고 차감을 검증했습니다. 검증 주문으로 각 상품 재고가 1개씩 차감되어 현재 99개입니다.
